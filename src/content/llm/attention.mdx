## Overview

Attention is the mechanism that lets a language model decide, for every token, **which earlier tokens matter most** when building its representation. Instead of blending all previous words equally, each token sends a *query*, compares it against the *keys* of the tokens it is allowed to look at, and pulls in a weighted mix of their *values*.

<Formula
  tex={'\\text{Attention}(Q,K,V) = \\text{softmax}\\!\\left(\\dfrac{QK^{T}}{\\sqrt{d_k}}\\right)V'}
  block={true}
/>

## Remember

- **Query (Q)** — what am I looking for?
- **Key (K)** — how well does each token match my query?
- **Value (V)** — what information is actually retrieved and combined?
- Raw scores are divided by <Formula tex="\sqrt{d_k}" inline /> so softmax never saturates as dimensions grow.
- **Causal masking** forces weight 0 for any token *after* the query — a decoder-only model cannot peek at the future.

## Summary

Attention turns reading into a soft, differentiable lookup: **scores → weights → weighted sum of values**. Every transformer layer repeats this in parallel across many heads; multi-head attention just does it several times with different learned Q/K/V projections.
